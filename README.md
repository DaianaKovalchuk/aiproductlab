## LLM Hallucination Risk Checker

Интерактивный веб‑инструмент на Python/Streamlit, который:

- **оценивает риск галлюцинаций** в ответе LLM (ChatGPT, Grok и др.) на основе семантической согласованности с исходным вопросом;
- выполняет **базовую фактологическую проверку** подозрительных предложений по открытым источникам (ru/en Wikipedia + веб‑поиск через Serper.dev, если настроен API‑ключ);
- генерирует **PDF‑отчёт** с итоговым скором и подсветкой рискованных фрагментов.

Целевая аудитория: студенты, журналисты и маркетологи, которые регулярно публикуют тексты и хотят быстро понять, где ответ модели стоит перепроверить.

---

## Структура проекта

- `app.py` — одностраничное Streamlit‑приложение (UI, обработка ввода, вывод результатов, вызов анализа и факт‑чека, экспорт PDF).
- `semantic_analyzer.py` — семантический анализ вопроса и ответа:
  - построение эмбеддингов для вопроса, ответа и предложений;
  - расчёт косинусного сходства;
  - агрегация в общий **риск галлюцинаций 0–100%** и пометка рискованных предложений.
- `fact_checker.py` — фактологическая проверка:
  - выбор «фактоёмких» или семантически рискованных предложений;
  - поиск кандидатов в ru/en‑Wikipedia и через Serper.dev;
  - сравнение смысла и чисел/дат, присвоение статусов **confirmed / partial / contradicted / no_source**;
  - структурный разбор чисел/дат (совпадают, частично совпадают, расходятся).
- `pdf_report.py` — генерация PDF‑отчёта с итоговым скором, метаданными и списком рискованных предложений.
- `requirements.txt` — зависимости Python.
- `.env.example` — пример файла с переменными окружения (нужно переименовать в `.env` и добавить реальные значения).
- `.gitignore` — исключения для Git (в т.ч. `.env` и артефакты Python).

## Установка и запуск локально

### 1. Подготовка среды

Требуется Python 3.10+.

```bash
cd путь/к/папке/проекта
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:

```bash
copy .env.example .env
```

2. Откройте `.env` в редакторе и, при наличии ключа Serper.dev, укажите:

```bash
SERPER_API_KEY=ваш_ключ_из_serper
```

Без этого ключа инструмент всё равно будет работать, но факт‑чекинг будет опираться только на Wikipedia.

### 3. Запуск Streamlit‑приложения

```bash
python -m streamlit run app.py
```

По умолчанию интерфейс будет доступен в браузере по адресу `http://localhost:8501`.

## Как пользоваться

1. В поле **«Вопрос, который вы задали LLM»** вставьте ваш исходный запрос (prompt).
2. В поле **«Ответ LLM»** вставьте полный ответ модели.
3. Нажмите кнопку **«Проверить»**.

Приложение:

- рассчитает **итоговый риск галлюцинаций (0–100%)** и коротко интерпретирует его;
- покажет блок **«Семантическая согласованность»**:
  - схожесть вопрос–ответ (cosine 0–1),
  - среднюю схожесть по предложениям и её разброс,
  - количество предложений;
- построит **гистограмму** распределения схожести по предложениям и текстовую аналитику по трём зонам:
  - низкая (< 40%), средняя (40–70%), высокая (> 70%) схожесть;
- выведет список **«Предложения с повышенным риском (семантика + факты)»**, где для каждого:
  - семантический риск и sim;
  - фактологический статус (подтверждено / частично / противоречит / нет источников);
  - при наличии — разбор чисел/дат (совпадают / частично / расходятся);
  - ссылка на найденный источник (Wikipedia или веб‑страница).

Внизу можно:

- скачать **PDF‑отчёт** с question/answer, итоговым скором и рискованными предложениями;
- использовать отчёт как приложение к статьям, курсовым, редакционным заданиям.

## Семантический анализ (semantic_analyzer.py)

Модуль использует мультиязычную модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, чтобы:

- получить эмбеддинги для вопроса, ответа целиком и каждого предложения ответа;
- вычислить:
  - косинусное сходство `qa_similarity` между вопросом и ответом;
  - сходство текста вопроса с каждым предложением ответа;
- агрегировать:
  - **mean_sentence_similarity** — средняя схожесть по предложениям;
  - **std_sentence_similarity** — разброс (насколько предложения неоднородны);
  - **overall_risk** — базовый риск `100 - mean * 100` плюс добавка за разброс (ограничена 30 п.п.).

Каждому предложению присваивается собственный `risk` (0–100), который учитывается в UI и PDF, а также используется как триггер для факт‑чекинга.

## Фактологическая проверка (fact_checker.py)

Факт‑чекер работает поверх списка `SentenceScore` и возвращает список `FactCheckResult` с полями:

- `status`:
  - `confirmed` — смысл предложения хорошо совпадает с источником, числовые значения не конфликтуют;
  - `partial` — источники описывают похожий факт, но формулировки и/или числа частично расходятся;
  - `contradicted` — смысл сильно расходится или найден явный конфликт по числам/датам;
  - `no_source` — подходящих источников не найдено или совпадение слишком слабое;
- `similarity` — семантическая близость предложения и фрагмента источника;
- `source_title`, `source_snippet`, `source_url` — метаданные лучшего найденного фрагмента;
- `sentence_numbers`, `source_numbers`, `numbers_status` — структурный разбор чисел/дат;
- `explanation` — короткое текстовое объяснение статуса.

Основные шаги:

1. **Отбор кандидатов**  
   В факт‑чек идут предложения, которые либо:
   - имеют высокий семантический риск;
   - содержат признаки «фактоёмкости» (цифры, годы, последовательности слов с заглавной буквы).

2. **Поиск источников**
   - ru/en‑Wikipedia через публичный API (несколько top‑результатов);
   - веб‑поиск через Serper.dev (если настроен `SERPER_API_KEY`).

3. **Сравнение**
   - строятся эмбеддинги предложения и всех сниппетов;
   - выбирается фрагмент с максимальной семантической близостью;
   - отдельно сравниваются числа/даты:
     - `match` — множества чисел совпадают;
     - `partial` — есть пересечение, но отличаются;
     - `mismatch` — есть числа, но они полностью разные;
     - `no_numbers` — чисел ни в ответе, ни в источнике.

4. **Присвоение статуса**  
   Комбинируются пороги по `similarity` и `numbers_status`, чтобы выдать один из статусов и пояснение.

## Генерация PDF‑отчёта (pdf_report.py)

Отчёт формируется с помощью `fpdf2`:

- используется системный шрифт `Arial` из `C:\Windows\Fonts\arial.ttf` для поддержки кириллицы;
- на первой странице:
  - заголовок и дата/время генерации;
  - исходный вопрос и ответ;
  - итоговый риск и метрики схожести;
  - текстовая шкала интерпретации score;
- далее перечисляются все предложения с их риском и similarity, предложения с высоким риском подсвечиваются красным.

Функция `build_pdf_bytes()` возвращает байты PDF для передачи в `st.download_button`.

## Обработка ошибок и граничные случаи

- Пустой вопрос/ответ:
  - пользователь получает понятные подсказки, что именно нужно заполнить;
  - анализ не запускается, исключения не выбрасываются наружу.
- Сбой семантического анализа:
  - перехватывается и отображается сообщение:
    «Что-то пошло не так при семантическом анализе. Попробуйте ещё раз позже.»
- Сбой внешних запросов (Wikipedia, Serper.dev):
  - модуль `fact_checker` возвращает пустой список, а UI честно пишет,
    что факт‑проверка временно недоступна или не нашлось подходящих источников.
- Генерация PDF:
  - все ошибки перехватываются, пользователь видит сообщение
    «Не удалось сформировать PDF‑отчёт…» вместо технического трейсбэка.
- Длинные тексты и спецсимволы:
  - Streamlit и `sentence-transformers` нормально работают с Unicode;
  - PDF‑генерация использует Unicode‑шрифт, чтобы избежать ошибок кодировки.

## Как разворачивать публично

Рекомендуемый путь — **Streamlit Community Cloud**:

1. Создать и заполнить репозиторий на GitHub (без `.env`).
2. Войти на `https://share.streamlit.io` под GitHub‑аккаунтом.
3. Создать новое приложение, указав репозиторий и `app.py` как основной файл.
4. В секции **Secrets** на Streamlit Cloud задать переменные окружения (например, `SERPER_API_KEY`).
5. Получить публичную ссылку вида `https://имя-приложения.streamlit.app` и поделиться с пользователями.
